Collected 30 October 2026. This inventory covers **only the 24 new files C060.mp3–C083.mp3**. It does not document or change the licences of the 87 pre-existing recordings.

## Attribution and licences

The recordings remain under the individual licences linked below; the app's code licence does not replace them. Preserve this attribution, the source links and the applicable licence when redistributing these audio assets. The authors and Wikimedia do not endorse IPA365.

Every new file was downloaded from **Wikimedia's actual MP3 transcode**, without further re-encoding, cutting, resampling, loudness adjustment or other audio edits by IPA365. Only the local filename was changed to the app's card ID. Wikimedia's conversion from the source Ogg/WAV to MP3 is identified in [sources.json](sources.json), together with the exact original and MP3 URLs, source file SHA-1, Commons page/revision, author-credit evidence and local validation/checksum.

## Phonetic caveats and review status

- **C073 / ʜ:** the Commons source is explicitly titled **Voiceless epiglottal trill**, not an independently verified fricative-only example. The existing app label “voiceless epiglottal fricative” therefore needs an educator's listening review before the recording is used as an exact illustration. [Source](https://commons.wikimedia.org/wiki/File:Voiceless_epiglottal_trill.ogg).
- **C074 / ʢ:** the Commons source is explicitly titled **Voiced epiglottal trill 2**. The same trill-versus-fricative qualification applies. [Source](https://commons.wikimedia.org/wiki/File:Voiced_epiglottal_trill_2.ogg).
- **C060–C064 / clicks:** recordings may include carrier vowels or accompanying closure/voicing. A basic click-place symbol does not specify every accompaniment. The complete source recordings are retained, not cropped into alleged context-free segments.
- **C079 / ɧ:** this is one realization of the sound identified by the Commons source; it should not be presented as covering every Swedish sj-sound variant.
- All other recordings likewise retain any original vowel context, repetitions and speaker variation. Source identification is not a claim of independently verified phonetic accuracy.
- All 24 files must decode as genuine MPEG Layer III MP3 with finite samples and a non-silent signal. These integrity checks do **not** substitute for listening review. No independent phonetic listening review has been completed.

Collection validation passed: **24/24** genuine, non-silent MP3s, with per-file SHA-256 checksums in the manifest. The **87 original recordings are byte-for-byte unchanged**. Eight isolated checks also passed, covering mapping/attribution, decoding/checksums, silent-audio rejection, falsely named MP3 rejection, overwrite protection, filename/scope restrictions, epiglottal caveats and genuine conversion fallback.

## Reproducing and checking the collection

From the project root, using the already installed Python 3.12 audio environment:

```powershell
# Download missing C060–C083 files and validate all 24.
& './experiments/ipa-lab/.venv/Scripts/python.exe' scripts/fetch_audio.py

# Offline integrity check; no downloads.
& './experiments/ipa-lab/.venv/Scripts/python.exe' scripts/fetch_audio.py --verify

# Inspect current Commons metadata; prints JSON without changing the reviewed manifest.
py -3.12 scripts/fetch_audio.py --metadata
```

The downloader uses the pinned URLs and SHA-256 checksums in [sources.json](sources.json), refuses to overwrite existing files, and never targets C001–C059 or any vowel recording. If Wikimedia changes a transcode, a checksum mismatch requires review rather than replacement. A Wikimedia rate limit stops the download so it can be retried after a cooldown.

A genuine soundfile-to-MP3 fallback is implemented for future metadata snapshots with no available MP3 transcode. It was **not used for this collection**. Re-encoding on a different library version is not expected to produce byte-identical MP3s.
